# 🔵 Area of Circle in C

A simple beginner-friendly C program that calculates the **area of a circle** using the radius provided by the user.

## 📌 About the Project

This project was created while learning the fundamentals of the C programming language.

The program takes the radius of a circle as input and calculates its area using the formula:

**Area = π × r²**

Where:

- `π` = 3.14159
- `r` = radius of the circle

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Enter the project directory

```bash
cd c-area-of-circle
```

### 3. Compile the program

Using GCC:

```bash
gcc main.c -o circle
```

### 4. Run the program

#### Windows

```bash
circle.exe
```

#### Linux/macOS

```bash
./circle
```

### Input

```text
Please Enter The Radius Value: 5
```

### Output

```text

```

## 📐 Formula

```text
Area = π × radius × radius
```

For example, when:

```text
radius = 5
π = 3.14159
```

The result is approximately:

```text
78.540
```

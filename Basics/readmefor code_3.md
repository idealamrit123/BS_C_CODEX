# Multiplication Table Generator

A simple C program that generates multiplication tables for a range of numbers.

## Features

- Choose the starting table.
- Choose the ending table.
- Set the multiplication limit.
- Uses nested `for` loops.

## Example

Enter starting table: 2  
Enter ending table: 5  
Enter table limit: 10

The program prints multiplication tables from 2 to 5.

## Language

- C

## How to Run

Compile and run the program using any C compiler.

```bash
gcc main.c -o table
./table
